# 第一批组合案例与颜色选择

案例使用独立 HTML 页面和 `src/cases-main.tsx` 入口，不挂载展示页的目录、实践区、API 或 `app.css`。展示站右上角「案例」是普通链接，跳到 `/cases/`。页面之间采用普通链接导航，共享组件库、基础样式与主题偏好。Vite 多页面构建包含所有入口，直接访问与刷新无需 SPA 路由。此批参考页面的工作区、工具分组与表面关系，使用 Uagray 组件和自有虚拟内容，不复制原作品、图片、品牌或作者文案。

## 详情页架构验证

参考 [Action camera](https://lab.anishfn.ink/action-camera) 和已存档的用户截图，按相同信息结构组合：浅灰主体展示区 → 局部白色工具层 → 标题与侧边页面操作 → 窄行宽说明与标签 → 关于 → 三列补充图文 → 两行元数据 → 前后导航。使用自制几何模块、说明与视角，未复制原站相机、图片、品牌或文案；按用户此前要求不添加装饰页脚与面包屑。

公共组件复用 PageShell、Surface、Layout、Button、Badge、ShareButton、Pager、NavigationCard。页面 CSS 负责栅格、阅读宽度和工具位置；模块图是案例内容。元数据使用原生 dl，插图使用 figure/figcaption，不为页面静态内容强造新组件。二维拖动只改变示例图的观察角度，支持左右键和重置。

当前系统能表达这一结构，但 PageShell 的默认最小高度、头部尺寸与页面间距仍需案例层适配；元数据与图文栅格尚无公共组合组件。这些是架构缺口，不以新增页面数量视为库已完善。浏览器视觉验收仍未进行。

控件、表面与面板全部复用 src/ui；语义表格与海报内容由案例布局组合，布局 CSS 只负责位置、容器宽度和示例内容。SaaS 的分页数量和标识颜色设置作用于案例，不修改全局 Token。案例数据保存在 React 会话状态，没有后台或持久化。原生 dialog 在 DOM 测试中仅验证状态生命周期，不能证明浏览器焦点捕获效果。

海报的几何边框、文字与填色属于示例内容，可使用所选颜色；UI 控件继续使用中性 Token。图片通过本地 Object URL 预览，替换与卸载时释放。文字 SVG 导出转义编辑文本，不包含上传图片；操作名称明确为“导出文字 SVG”。

## ColorPicker

组件使用二维饱和度/明度面板、色相滑条和棋盘格透明度滑条。支持 HEX、RGB、HSB、HSL 数值编辑，格式切换不改变当前颜色；透明度始终独立可调。无样式交互与颜色转换采用 [React Aria ColorPicker](https://react-aria.adobe.com/ColorPicker)，周边字段与按钮复用 Uagray。

| API                  | 契约                                                 |
| -------------------- | ---------------------------------------------------- |
| value / defaultValue | 受控 / 非受控 HEX，接受带或不带 # 的 3、4、6、8 位值 |
| onValueChange        | 输出 #RRGGBB；非完全不透明时输出 #RRGGBBAA           |
| label                | 选色面板与 HEX 字段的可访问名称                      |
| disabled             | 禁用所有交互                                         |
| className            | 宿主布局扩展；默认填充父容器                         |

保持单件选色面板，调用方决定是否放入弹层；不把弹层标题与关闭按钮强塞进组件。内部保留 HSB 模型，在灰色、黑色时调整色相后，再提高饱和度/明度不会丢失色相。HEX Enter/失焦提交；非法编辑保留草稿与错误，Escape 恢复当前颜色。吸管采用原生 EyeDropper，仅在支持的浏览器中启用，采样保留透明度；取消不报错，卸载中止采样。暂不包含渐变编辑或页面颜色自动扫描。

配色内容允许彩色；面板为 raised 表面、轻边界，无嵌套灰色卡片和额外阴影。色相/透明度轨道与二维面板的渐变表示真实颜色值，不作为 UI 装饰。数值字段统一采用 control 尺寸、常规字重。格式字段、颜色值与透明度同排；字段名称仅供辅助技术读取，不显示冗余标题。已移除预设色板及 presets API。

## 验证边界

定向测试覆盖 HEX 归一化与非法输入、二维选色、色相、透明度联动、格式切换、吸管成功与取消、受控值更新、禁用；案例搜索与空结果恢复、版式/颜色/缩放重置、项目表单校验与批量完成。既有回归测试继续执行。未使用浏览器工具，视觉、原生键盘步进、图片预览及文件下载体验须在实际页面核对。
