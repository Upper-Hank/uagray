# ColorPicker 契约

组件使用二维饱和度/明度面板、色相滑条和棋盘格透明度滑条。支持 HEX、RGB、HSB、HSL 数值编辑，格式切换不改变当前颜色；透明度始终独立可调。无样式交互与颜色转换采用 [React Aria ColorPicker](https://react-aria.adobe.com/ColorPicker)，周边字段与按钮复用 Uagray。

| API                  | 契约                                                 |
| -------------------- | ---------------------------------------------------- |
| value / defaultValue | 受控 / 非受控 HEX，接受带或不带 # 的 3、4、6、8 位值 |
| onValueChange        | 输出 #RRGGBB；非完全不透明时输出 #RRGGBBAA           |
| aria-label           | 选色面板与 HEX 字段的可访问名称，必填                |
| className / style / ref | 宿主布局扩展；ref 指向面板根节点。默认填充父容器     |
| disabled             | 禁用所有交互                                         |

保持单件选色面板，调用方决定是否放入弹层；不把弹层标题与关闭按钮强塞进组件。内部保留 HSB 模型，在灰色、黑色时调整色相后，再提高饱和度/明度不会丢失色相。HEX Enter/失焦提交；非法编辑保留草稿与错误，Escape 恢复当前颜色。吸管采用原生 EyeDropper，仅在支持的浏览器中启用，采样保留透明度；取消不报错，卸载中止采样。暂不包含渐变编辑或页面颜色自动扫描。

表面、数值字段与颜色内容的视觉分工见 [设计规范的组件契约](design-system.md#组件与组合契约)。已移除预设色板及 presets API。

## 验证边界

定向测试覆盖 HEX 归一化与非法输入、二维选色、色相、透明度联动、格式切换、吸管成功与取消、受控值更新、禁用。浏览器视觉、原生键盘步进与选色体验仍须按实际任务验收。
