# Uagray 组件与页面审查

审查日期：2026-10-09。依据 [设计原则 0.2 工作稿](design-system.md) 的 R1–R10。

## 范围与结论边界

已按源码逐项核查目录中的 37 个组件，补充 CopyButton、ShareButton，检查共享详情模板、3 个规范入口、5 类 Token 展示、4 个独立案例页，以及主题、图标、滚动条和动效基础设施。

这是源码审查，未使用浏览器，未运行构建或测试。下文“已有基础”表示存在相应实现，不代表视觉与交互验收通过；“待确认”表示规则或实际视觉证据不足。原站观察只作为讨论证据，不作为所有组件的合格标准。

整体结构已经具备复用基础：库和展示层分离、语义 Token、原生与 Radix 语义、共用图标适配、独立案例、统一详情模板都已存在。主要矛盾集中在表面组合、状态表达、接口职责以及展示能否真实检验组件，不能仅靠再换一批色值解决。

优先级：P0 为已发现的受控状态可靠性问题；P1 为妨碍规范落地、信息识别或可用性检验的问题；P2 为统一尺度、完善默认行为和待场景校准的问题。优先级不是本轮自动实施授权。

## A14：混合工具栏缺少有效留白契约

发现：规范演示“当前视图 / 重置”左侧为裸 Icon，右侧为带内部 padding 的 Button；相同容器 padding 产生不同有效外缘。spec-tools 的 4px inset 未检查子项是否拥有协调留白，6px gap 也不能自动协调裸内容与按钮之间的距离。
