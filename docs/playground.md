# 组件 API 调试契约

更新日期：2026-10-11。公共内容 API 采用 children 与语义子组件，见 [API 规范](api-contract.md) 和 [逐组件实施清单](component-api.md)。调试源码在 `src/`，不进入组件包。

## 预设与自定义

组件详情采用预览区与配置区。配置区提供「预设 / 自定义」切换，预设选择独立于真实 API 参数。预设是完整内容、属性及必要行为的起点；Button 提供按钮、复制按钮、分享按钮。其他条目使用现有完整示例作为初始预设，不提供个人预设持久化。

进入自定义时，从当前预设及实例状态建立内容树。返回预设时恢复当前预设的完整配置，丢弃自定义修改和未提交草稿。选择另一个预设同样覆盖完整配置。「重置示例」恢复当前预设，保留自定义/预设模式及预览环境，清理文件反馈并关闭编辑 Dialog；它不是恢复组件默认值。

配置区直接编辑常用枚举、布尔与数值参数，并以节点列表呈现 children。children 标题右侧并排提供设置与添加图标；设置只管理当前 children，不编辑组件自身属性。点击节点进入编辑，左侧手柄用于拖动排序，可删除节点的删除图标常驻显示。节点列表只显示真实节点名称、内容摘要及可用操作，不各自套卡片。完整属性、文字和内部 children 在本系统 Dialog 中编辑；组件自身属性（包括 value、placeholder 等）在配置区直接编辑。

视觉、布局、环境及几何只维护在 [设计规范](design-system.md#展示与设计实践)。普通参数单元按可用宽度排列，名称在编辑对象上方，最大宽度 360px。环境切换只影响预览承载，不进入属性、代码或重置范围。

## 内容树与编辑事务

`playground-tree.ts` 的 ContentNode 保存稳定 id、组件/语义子组件类型、真实属性、文字及 children。文字是独立节点；ExpandableCode.Body 保留单一字符串正文与复制源。新建节点与预设提供初始内容，删除后不补回。库的 ReactNode 能力不被编辑器的已注册组件集合缩窄；编辑器不执行 JSX 字符串，不检查业务组件的渲染输出。

- 添加节点先打开 Dialog，再从当前区域允许的组件中选择并配置；确认前不进入预览或代码。
- 节点编辑使用完整内容树草稿。直接编辑或添加不提供多余的返回步骤；从 children 管理或节点内部继续进入子节点时，沿同一个 Dialog 前进与返回，返回保留本次事务的草稿，不嵌套一串节点 Dialog。
- 保存时检查完整草稿的数量、依赖、嵌套、名称与身份关联；成功后一次提交。取消、关闭、Escape、切换模式、重置和收起 API 均丢弃未提交草稿。
- 数量、min/max、依赖和排列规则留在内部注册表。已达 max 的添加入口不出现；删除会破坏整体有效性时不提供该动作。自由内容和关联项通过手柄拖动排序；手柄聚焦后也可用上下方向键移动，固定职责槽位不提供任意排序。
- Button 至少保留 Icon 或有效 Label；Count 依赖 Label。纯图标 Button 必须在实际按钮上提供可访问名称。Icon、Label、Count 各最多一个；复制反馈的 pending/success/error 各最多一个。
- 行内区域只提供适用的非交互内容，不把 Button、Input 等嵌入按钮、标签或链接。Field.Control 承接一个字段；图标区域承接一个 Icon。Surface 环境与 PageShell 主内容结构不在后代重复嵌套。
- Dialog.Body、Tabs.Content 等开放区域支持继续添加适用的 Uagray 组件，并编辑其内部 children。
- TextList 使用原生 li；DescriptionList 的内置示例以 div 内的 dt/dd 配对初始化。该编辑模板不成为公共 dl 的唯一内容模型。

## 属性与资源

`playground-catalog.ts` 保留条目、真实属性元数据与完整预设值；`playground-tree.ts` 将预设转换为内容树，并登记节点的允许内容与详细属性。元数据中的类型、必填、默认值、签名和说明不在配置区、Dialog 或提示浮层展示；页面不提供“契约”入口。不将全部继承原生属性做成调试控件。

根组件只编辑自己的外观、状态、行为和约束；子节点编辑自己的属性。Button 的 action 是预设内部选择，不是公共属性；showCount 不进入配置。CopyButton.text、ShareButton.url 是操作数据，在对应节点的详细设置中编辑，不从可见内容反推。

tone 只展示组件支持的语义色样；emphasis 与枚举 size 使用实际样本和原生 radio。Icon.size 保持数字像素。图标选择复用完整已安装 uplus 元数据、动态入口、搜索与预览，不维护精选白名单。数值使用 NumberInput，布尔使用 Switch，其余枚举使用 Select；文字使用原生语义字段，详细内容使用 Textarea。

Select、SegmentedControl 的 Item 和 Tabs.Trigger 的 value 非空且唯一；标签编辑与排序不重建节点 id 或 value。Tabs.Content 的 value 对应一个已有 Trigger，且各面板身份唯一。添加面板只提供尚未建立面板的 Trigger；删除关联 Trigger 前先移除对应 Content。修改关联身份可在完整树草稿内一起完成。添加、删除或禁用选择项后，将当前值归一化至有效项，无可选项时为空；此为编辑器行为，Select 的触发器显示与组件库行为保持原契约。

Slider/NumberInput 的 min/max/step/value、SelectionBar 的 count/total、Progress 的 value/max 在已提交内容树中归一化，实例和代码读取同一结果。Progress 可显式省略 value 表达不确定进度。0、false 和未提供属性分别处理，不用真假判断代替存在判断。

## 状态与生成用法

预设模式保留现有完整示例渲染和代码生成；自定义模式使用同一 ContentNode 树生成预览与用法。实例交互回写对应节点的已提交属性，配置修改同步实例。草稿有错误时保留先前有效预览和代码。

`playground-tree-view.tsx` 通过已注册组件创建 React 节点，代码生成只输出 JSX 文本。生成用法使用 `uagray` 与 `uagray/styles.css` 公共入口，按实际节点输出受控状态与真实回调，不输出编辑器 id、内容数组、模式、环境或槽位规则。各节点有独立状态变量；嵌套字段不共享 value，多个文件区分别保留文件反馈。

Dialog/Drawer/Toast 有可执行的打开入口。ConfirmDialog 的确认关闭示例，取消由语义动作处理；SelectionBar 的语义动作连接根 count 的变化。弹层预设的关闭按钮保留关闭行为，弹层内新建的 Button 可在详细设置选择关闭所在弹层。代码与预览遵循同一行为。

用法保留单个 Disclosure，默认收起，完整代码可复制。折叠用法不丢配置，不生成日志面板或模拟成功流水。

## 焦点与验证边界

字段仅 Tab 定位显示轻量提示，鼠标点入与普通输入不启用外圈。共享 `src/ui/focus.ts` 维护导航意图，保留真实 DOM 焦点、光标、原生键盘语义；非文本操作保留 focus-visible。模态、Select 和图标选择沿用组件库的焦点契约。

本轮进行类型检查、设计声明检查、配置台定向交互测试和生成用法类型检查；生成检查覆盖现有预设、自定义初始树及嵌套字段/动作组合。未启动浏览器或执行完整构建、消费验证；实际窄屏、光学和浏览器交互仍未验收。
