# Uagray · v0.1 全站打磨

> 历史参考材料：仅保留当时的观察、讨论或实现快照，不作为现行规范。现行设计依据见 [设计参考规范](../../design-system.md)。
> 日期：2026-10-10。依据 [视觉准则](../../design-system.md) P01–P10。用户授权网站与全部现有组件打磨，并允许调整 API、要求逐项说明；本轮明确选择只做源码与定向测试，不进行浏览器验收。

## 实施范围

覆盖目录中的 37 个组件条目、CopyButton/ShareButton、三个规范入口、五类 Token 展示，以及案例总览、模块详情、编辑工作台、SaaS 项目空间。保持已有功能、内容与独立页面入口，没有增加依赖、组件品类或包发布工作。

方向是职责一致，而非所有组件形状一致：颜色资源、对象边界和实体感分开；环境只提供可辨认的默认资源；连续内容不自动围合；选中、状态、进度和浮层由各自组件承担。

## 公共 API 与宿主迁移

| 项目                                        | 变更                                            | 兼容性与迁移                                                                                        |
| ------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Surface.treatment                           | 新增可选 tonal / defined / physical，默认 tonal | 旧调用保持色差处理；静态独立编辑区显式 defined，实体工具显式 physical。tone 不负责边缘或阴影        |
| SurfaceProps                                | 公开类型，支持原生 div 属性及 ref               | 增量能力；aria、id、style 与事件转交根元素。库不新增任意 border/shadow 开关                         |
| ui-tool-surface                             | 只提供工具几何，不自动加阴影                    | 依赖此样式类的宿主应显式传 treatment；本仓库所有调用已迁移                                          |
| ui-action-surface / ui-action-surface-hover | 普通动作使用独立资源                            | 只覆盖 element 的宿主现在只影响编辑/选择区域；需要改变动作时覆盖 action-surface，避免牵连进度和状态 |
| ui-range-track                              | 进度与轨道的独立资源                            | 不再继承灰容器中的白色 element；金额/进度不会被当作子卡片                                           |
| ui-edge / ui-elevation                      | 独立边缘与轻阴影资源                            | ui-shadow 保留为 Physical 的组合便利值。宿主无需更改现有变量引用                                    |
| Button / Input / Tabs 等                    | 保留现有公共 props 与事件                       | 调整默认几何、状态和资源消费；没有为候选 Outline 外观新增变体                                       |

Surface 用法：

```tsx
<Surface tone="raised" treatment="defined">静态编辑内容</Surface>
<Surface tone="raised" treatment="physical">悬浮工具</Surface>
```

`raised` 保留兼容名称，不代表空间抬升。Tonal/Defined/Physical 不是高低阶梯。透明动作与共享底座仍通过已有 plain/tone 接口组合。

## 组件覆盖与决策

以下为源码覆盖记录，不表示逐件视觉验收。

| 组件                                                     | 本轮处理与保留的职责                                                                                                          |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Button、CopyButton、ShareButton                          | 左右内容内距统一；常态前景使用操作文字角色；普通动作不因灰背景获得阴影。white 保留既有实体动作职责，但 hover 不增强阴影       |
| IconButton、ExternalLinks、Pager                         | 普通/小尺寸跟随控件尺度；组内箭头保留 inset、局部底色和前景反馈，Pager 点击不缩放，禁用项保留语义                             |
| ButtonGroup、SelectionBar、Layout                        | 共同边界、单元内部留白、组间距离分责；共享底座的子动作常态透明；布局组不自动增加底色                                          |
| SegmentedControl、Tabs                                   | 共用平滑指示块和留白；主标签 hover/选中变深，计数独立固定常态色；分别保留 radio/tab 语义与键盘行为                            |
| Input、Textarea、NumberInput、SearchField、Select、Field | 标签和值统一角色尺度；字段与动作资源分开；提示/错误由需要它的字段提供；保留草稿、验证和键盘焦点；API 整单元只在键盘定位时提示 |
| Checkbox、Radio、Switch                                  | 小选择标记有可识别边缘；选中消费 action/on-action 成对资源，不用正文颜色偶然充当动作色。Switch 轨道与 thumb 不再随灰容器翻转  |
| Slider、Progress                                         | 轨道资源与容器 element 分开；标签与数值沿操作轴排列，进度保留数量语义；滑块实体感与 filled 进度独立                           |
| Disclosure、ExpandableCode                               | 默认折叠区共享基底，以分隔表达阅读范围；用法只有一层阅读边界。独立代码展开仍保留原有功能及灰色辅助动作                        |
| Dialog、Drawer、ConfirmDialog、Toast                     | 保留真实浮层的阴影与主题表面；内部重置字段/动作资源；原生 dialog 生命周期、确认和超时行为保持                                 |
| Badge、Alert、EmptyState                                 | 状态前景/背景由 tone 成对管理，不因祖先灰底一律翻白；Badge 使用 12px 阅读尺度；空状态不自动加卡片                             |
| FileDropzone                                             | 拖放区域作为明确输入对象，以虚线边界识别；选择文件动作使用局部对比资源，不强加白按钮阴影                                      |
| ColorPicker                                              | 白色静态编辑区与明确边界；颜色本体不受中性 UI 调色规则限制。通道增加 R/G/B、H/S 等紧凑标识与百分比；按自身容器宽度安排通道    |
| Surface                                                  | 色彩 tone 与边界 treatment 独立；环境只提供字段与普通动作资源，取消 action-shadow/status/selected/range/switch 的统一祖先映射 |
| ShowcaseCard、NavigationCard                             | 保留卡片整体动作与外链独立动作的语义差异；局部标题不获得白色按钮身份，外链操作保持自己的边界                                  |
| Keycap、Icon、PageShell                                  | 键帽保留实体识别，图标统一上游适配 1.25、字重 450 不参与状态变化；页面结构无额外卡片或自动文案                                |

## 页面组织

- 规范页：P01–P10 全部呈现，文字与对应场景演示并行，不增加题注；交互与布局页保留功能演示。
- Token 页：连续列表、阅读分隔和复制动作，不再每行一个灰 Surface 或重复类型 Badge。
- 组件详情：灰任务范围 + 组件预览 + 白色 Defined 配置区；参数为完整浅灰编辑单元；长文本按需展开；用法一层白色阅读边界。Tabs 增加 contents 展示辅助项，输出真实 items[].content，不泄漏为公共 props。
- 案例总览：筛选与作品对象分工，卡片交互语义保持。
- 模块详情：阅读标题/简介/正文/元数据分配角色，保留关联视角和共享元数据区域；悬浮工具显式 Physical，窄宽允许完整动作单元换行。
- 编辑工作台：画布、作品与悬浮工具分别负责边界；图片、缩放与导出仍是功能单元；颜色编辑器在窄侧区按自身宽度重排。
- SaaS：指标、筛选、批量动作、项目表与设置保持连续基底；选中行局部提示；表头/文字/编辑动作沿同一阅读轴，去除逐项卡片化。

## 验证与限制

类型检查通过；受影响组件、颜色编辑、详情配置和四个案例共 55 项定向测试通过。新增 Tabs 内容编辑/切换/重置/代码同步验证；既有规范页测试改为定位对应规则的演示，避免跨示例共享状态造成歧义。

源码检查包括变量定义、状态消费、原生语义、有效留白、窄容器策略、主题资源与减少动态效果。浅色轻量文字 #696969 对 #ececec 的计算对比度约 4.65:1，暗色 #a0a0a0 对 #343434 约 4.76:1；这不是整个网站的可访问性验收。

遵守用户选择，本轮未使用浏览器。真实渲染、视觉重量与动态节奏仍需在页面中评审，不将源码/DOM 测试通过写成全站视觉验收通过。
