# 源码推送边界

本轮仅共享组件库源码及工程配置。未完成的展示、API 演示和测试案例全部移动到 Git 忽略的 `local/site/`；不以隐藏入口代替源码隔离。公共组件的真实属性和交互逻辑继续保留在 `src/ui/`，组件交互测试也继续跟随源码。

库构建不读取本地页面、字体或 HTML。展示站字体声明移到本地站点，组件 tokens 保留系统回退。npm 包使用 `files` 白名单，只收录组件库构建产物。

首次提交已包含这些页面。普通删除提交只能让后续版本不包含相关内容，不能从既有 Git 历史中清除；本轮不改写已存在的历史。若要求历史也完全排除，应另行确定远端历史重写或新建干净仓库的方案。

本地展示站的使用命令见本机 `local/site/README.md`，远端无需该目录即可构建库。
