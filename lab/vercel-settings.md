# 第四题：Vercel 项目设置

## 来源与范围

参考官方 [General Settings](https://vercel.com/docs/project-configuration/general-settings) 与 [Environment Variables](https://vercel.com/docs/environment-variables) 中的项目名称、根目录、框架与构建、变量环境范围及项目管理任务。原型名为 Launch，项目、团队与变量值均为虚构内容。

只参考信息架构与任务关系，视觉采用 Uagray 主规范；不连接 Vercel，不执行构建或部署。原型只位于内部 `lab/`。

## 组件与任务

| 页面职责 | 组件与宿主处理 |
| --- | --- |
| 设置分区 | Button、Icon；宿主维护当前分区与 aria-current |
| 独立保存 | Field、Input、Button；名称、根目录和构建各自维护草稿 |
| 构建预设与覆盖 | Select、Switch、Input；只读预设与可编辑覆盖切换 |
| 环境变量目录 | SearchField、Select、Badge；宿主过滤名称与环境 |
| 变量编辑 | Dialog、Field、Input、Checkbox、Switch；验证名称、内容和环境交集 |
| 删除变量 | ConfirmDialog；确认后移除指定变量 |
| 转移与删除项目 | Dialog、Select、Input、Button；转移保留数据，删除校验准确名称 |
| 保存异常与删除结果 | Alert、EmptyState |

保存行使用统一控件间距并允许换行，源码检查登记此契约。页面没有扩充库 API 或增加依赖。

## 已实现与差距

名称、根目录和构建配置独立保存。禁用覆盖时恢复当前框架的命令与输出预设；启用后校验命令与目录非空。切换分区会丢弃未保存草稿，没有跨分区草稿恢复或离开提醒。

变量支持搜索、按环境筛选、显隐、新建、编辑和确认删除。同名变量允许不相交的环境集合，环境重叠时拒绝保存。值默认遮蔽；遮蔽仅控制显示，本机存储为明文示例数据，没有实现真实平台的密钥管理、分支级覆盖与远端同步。

部署保护只有本机配置开关，没有实现身份策略。团队转移保留所有设置和变量；删除项目需输入准确名称，删除后可重建初始示例。没有实现权限、域名、部署记录、平台请求或真实转移 / 删除。

定向测试覆盖分区内独立保存、变量重名校验与环境范围、构建覆盖保存和恢复预设、转移保留配置、准确名称删除与变量清理。真实焦点返回、变量长值、窄屏表单和深浅表面关系仍需浏览器观察；当前未使用浏览器验收。
